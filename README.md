# Junction 2026

**Mandate**: a purchasing agent for professional kitchens on Valio Aimo's catalogue. It plans from the menu, handles the week's surprises with substitutes ranked by the kitchen's own rules, and asks before it acts. Exact-term approvals, no double orders, every decision traced.

Hackathon repo for Junction 2026 (Espoo, 13–15 Nov 2026). MIT licensed.

- Agents and contributors: start at [CLAUDE.md](CLAUDE.md).
- Current state: [docs/STATUS.md](docs/STATUS.md) · Plan: [docs/PLAN.md](docs/PLAN.md)

## Data
Product data, prices and availability come from the Valio Aimo mock catalogue and API provided for the Junction 2026 'Trusted Trade Agents' challenge. The repo holds only small derived samples (`fixtures/seeds/`, `evals/`); the full dataset is loaded into the database from a local copy and is not redistributed here. Venue data © OpenStreetMap contributors (ODbL).
