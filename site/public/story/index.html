A purchasing agent that stays inside the chef's limits.

Mandate plans a kitchen's orders from its menu and finds substitutes when Valio runs out of something. It orders on its own only within limits the chef wrote down. Anything else waits for the chef.

The kitchen screen, the chat and an outside agent over MCP or REST use the same tools. An approval is tied to the exact lines and prices. Sending the same order twice returns the same receipt. An outside agent can plan but cannot approve.
