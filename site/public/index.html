An agent that orders for your kitchen, only inside the limits you set.

Mandate plans a kitchen's order from Valio Aimo's catalogue, finds substitutes when products run out, and orders on its own only within the chef's mandate. Everything else waits for a person, with the reason.

      Every door goes through the same checks

      The kitchen screen, the chat and outside agents all call one gate. The limits are data, checked in code at the moment of ordering, so no model can talk its way past them.

      Who asks

      • Kitchen screen the chef
      • Chat our agent
      • MCP your agent
      • REST your code

      One gate

      • The mandatewhat the agent may buy alone, and what the chef never delegates
      • Spend caps and a hard limitheld even when an order is split
      • The exact termsa price or quantity change voids the approval
      • Cut-off and pack sizesa passed cut-off or a part pack is refused

      What happens

      • Ordered, with one receipt
      • Held for a person, with the reason
      • Refused, with the reason

      Products whose stock Valio doesn't state are labelled unknown and never counted as covered. See how it's built

      Bring your own agent, and try to make it overspend

      Your agent gets the same tools over MCP and REST as ours, inside your own sandbox. It can plan and order within the mandate. It has no tool to approve, and the gate refuses it if it tries.

      1. Get a key. Open app.mandate.kitchen/agents to mint one for your sandbox.

      2. Connect. Point any MCP client at https://app.mandate.kitchen/mcp/k/<key>.

      3. Start. Call get_context, then ask it to plan the buffet. Then ask it to approve.

      What's real, what's simulated

      Each screen in the app carries the same labels.

      • RealValio Aimo's catalogue, and live price and availability calls for shortlisted products, cached with the time fetched.
      • SimulatedThe booking, the clock, stock on hand, recipes, and the order itself. Valio's API has no order endpoint, so nothing is sent to Valio.
      • ModelsGemini reads requests and ranks substitutes. Every check that decides what may be ordered runs in plain code. A model can add a caution that holds a line, never one that allows it.
