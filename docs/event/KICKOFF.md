## Partner details not on the platform
- **Google DeepMind / Gemini:**
  - **Credits:** one API key per team (up to 5 people), emailed tonight via AI Studio.
  - **Side prize:** "big prize money" for building Gemini into the app in a cool way.
  - **Models:** the Gemini 4 family is new: *Argon* (frontier), *Carbon* (coding, long-horizon tasks, orchestrating sub-agents, 3D, UI) and *Hydrogen* (a fast flash model released yesterday).
  - **Decisions API ("Jev"):** a new, very fast decision model that answers up to 1,000 yes/no or classification questions in one call. Ideal for "may the agent do this alone, or ask a human?" (A `typesafe-ai` skill on this machine covers Jev.)
  - **Live audio model:** talks while running tool calls in the background, and switches languages, Finnish included.
  - **Smart transcription:** handles self-corrections and supports a custom vocabulary.
  - Gemma runs on device. A Gemini API agent skill is available (QR code / their booth).
- **NVIDIA:**
  - **Bounty:** 2 teams win an RTX GPU for building on **Nemotron 3.5 Super VL**.
  - **Model:** 120B mixture-of-experts (12B active), multimodal, open, served via Verda.
  - **Access:** ask in the NVIDIA channel on Discord for a Verda inference key.
- **Valio Aimo** brings product data, **mock APIs** and mentors. The question it poses: "When does your agent know it's safe to order on its own?"
- **S-Bank** brings a **massive synthetic dataset**; a mobile-first prototype is expected.
- **AstraZeneca** brings a background pack plus public cancer-registry data, and oncology mentors on site.
- **Stoa** judges accuracy, how clearly the reasoning is shown, creativity and **low inference cost**.
- **City of Espoo**, more detail:

  - fair, transparent discovery **without automated screening**;

- **Oxylabs** tech challenge: a working live-web feature (search and scrape with sources) inside your main project.
- **Cala:** the Saturday 11:00 workshop, and the booth for help.
