## Gaps Mandate can own (judgement)
1. Enforceable delegation for B2B food ordering (AP2/ACP are consumer and payment oriented; food tools only have value ladders).
2. Approval bound to exact terms (beyond a 7-day price hold).
3. A wholesaler interface any outside agent can read: catalogue, availability, cut-offs and policy over MCP/REST. Choco reads messy input on the supplier side, but there is no open door for outside agents.
4. Substitutes with reasons: recipe fit, allergens, price change.
5. Standing-order drift detection. Nobody shows one; Sysco's critical-item warning is the closest.
6. One wholesaler case spanning many kitchens (recall, regional shortage).

**Means for us:** see [SURFACES.md](../concept/SURFACES.md) §2b. **Pitch risk:** Choco's Autopilot already claims "only genuine exceptions reach a person". Our answer is that the exceptions rule is the customer's mandate, enforced in an open interface any agent can use and bound to exact terms. Choco's is a vendor feature inside its own app.
