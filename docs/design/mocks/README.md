# UI mocks (Sat 14 Nov, design session)

Static HTML mocks, kept so later design sessions can compare them with the live app. Numbers come from `shared/scenario.js` and are illustrative; never copy them into the app. Open `index.html` (it maps every mock), or serve the folder: `python -m http.server 8765`. Which parts moved into the app, and why: [handoff/ui-mockset-to-prod.md](../../handoff/ui-mockset-to-prod.md).

**User, Sat late, in retrospect:** `kitchen-a.html` reads cleaner than the live Kitchen, though it isn't complete enough (it lacks per-line control, rules, the rail and the full order flow). The ring 6 design session compares `kitchen-a.html`, `kitchen-b.html` and the live Kitchen at 1440 and 390, takes A's structure and calm as the baseline, and adds what the live app has that A lacks.
