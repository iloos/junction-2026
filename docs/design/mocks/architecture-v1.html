Architecture

Many doors, one gate, one record.

Every screen, every agent and every API call goes through the same tool registry and command handler. The core is pure TypeScript. Every outside service sits behind a port with a real adapter and a fallback, so the demo survives a dead API, and you can see which one answered.

State you can trust

Three small state machines carry the whole product. An edit always voids the approval. A commit happens once.

Plan

Any edit returns it to draft and clears the terms hash.

Line

Held lines carry a tier and reasons; unknown stock is never cover.

Approval

Bound to plan version + terms hash + mandate version + expiry.

Design choices

Pure core, ports at the edgesrc/lib/core has no Svelte, no DOM, no SDK. Lint enforces it.
One function changes stateapplyOps: 8 op types, versioned, every op logged with actor and door.
Approval is a hashtermsHash(deliverBy + sorted lines). A changed price can't ride an old yes.
Never hold a lock across a modelValio and Gemini run before the transaction; the lock covers only the write.
Every flow has a fixtureLLM_PROVIDER=fixture in the gate; ~420 tests and evals through the real handlers.
Words are a contract“Supplier confirmed” only with a receipt. VOCABULARY.md is enforced in tests.
