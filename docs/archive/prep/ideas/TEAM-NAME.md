# Team name

Needed by the **Fri 23:55 pre-submission draft**. **Decided: `j(x)`** (D2). Solo team.

## Where it came from
A search-engine chat that started at "junction synonyms" and went downhill into maths:
Function Junction → `f(x)` → `j(x)` → "is that 'function of Junction' or is it `f(j)`?" → "my name starts with J too" → "can we make a formula using both?" → `f(j(x))`.

The joke that makes it fit *this* repo: CLAUDE.md has said `Challenge: TBD` for weeks. We registered for a hackathon whose challenge was an unknown variable. We are literally `j(x)`, and Friday 19:30 is when we learn x.

## Readings of `j(x)`
- **j = Junction**, x = the challenge: the event applied to whatever problem lands.
- **j = the team as the function**: takes x (challenge, coffee, data) and returns a demo.
- **j = me**: a solo team, so the function really is one person. Nothing to hide.
- **Engineer bonuses**: `j` is the imaginary unit in electrical engineering (`j² = −1`), a p–n *junction* is EE's own junction, and `J(x)` is the Bessel function. Nobody needs these, but people who spot them will grin.

## Candidates
| Name | Says aloud | For | Against |
|---|---|---|---|
| **`j(x)`** | "jay of x" | 4 chars, reads as `f(x)` at a glance, x = unknown challenge | parentheses may break slugs and hashtags |
| `f(j)` | "f of jay" | literally "function of Junction" | weaker visual pun, j is only the input |
| `f(j(x))` / `(f∘j)(x)` | "f of j of x" | the "use both" formula | mouthful; `∘` won't survive forms |
| `j(us)` | "jay of us" | team-first | solo, so "us" is a lie |
| Function Junction | as written | universally readable | everybody's first idea; someone else will have it |

## Proposal
**Team name `j(x)`**, ASCII fallback `jx` wherever symbols are refused (URL slug, repo, Discord handle).

Payoff in the pitch: first slide `j(x)`, last slide `x = <our challenge>` → `j(x) = <our product>`. "We signed up before we knew x. Here's what we solved for." The name gets its punchline exactly once, at the end.

Skip the composite formulas: a name that needs explaining loses to one that gets a smirk.
