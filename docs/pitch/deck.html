The path every request takes.

Every request, from any of the four ways in, passes the same checks before anything is ordered

Three state machines hold the rules.

Plan

Any edit sends it back to draft and clears its terms, so an earlier approval no longer applies.

Line

Inside the mandate: ordered without asking. Otherwise it waits for the chef, or can’t be ordered at all.

Approval

Tied to the plan version, the exact terms and an expiry. Change any of them and the order is refused.

Each rule has its test in the repo
